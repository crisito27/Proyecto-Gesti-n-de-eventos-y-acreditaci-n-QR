# Integración de esta entrega en GitHub

La sesión no dispone de credenciales de escritura. No se ha publicado esta
versión ni se ha cambiado la rama predeterminada.

1. Guardar o confirmar cambios locales existentes antes de integrar.
2. En el clon del equipo, actualizar develop desde GitHub.
3. Crear una rama feature/cierre-rubrica.
4. Copiar los archivos del ZIP sobre ese clon conservando su carpeta .git.
5. Revisar git diff para evitar sobrescribir avances posteriores del equipo.
6. Ejecutar lint, pruebas y build dentro de taller2-react.
7. Hacer un commit que identifique el apoyo de Codex y la revisión real realizada.
8. Subir la rama y abrir un PR hacia develop.
9. Otro integrante revisa código y demo antes de fusionar.
10. Integrar develop hacia main y entregar ese enlace.

No atribuir los cambios generados automáticamente a trabajo manual ni crear
commits ficticios para simular participación individual.
